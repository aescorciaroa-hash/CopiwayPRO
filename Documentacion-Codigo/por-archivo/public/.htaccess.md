# `public/.htaccess` (y el `.htaccess` de la raíz)

## Ubicación
`public/.htaccess` — más un segundo archivo en la raíz del proyecto: `.htaccess`

## Propósito
Configurar **Apache** (el servidor de Laragon) para que todas las URLs pasen por
`public/index.php`, menos los archivos que existen de verdad. Son dos archivos porque el
proyecto tiene que funcionar de las dos formas: con el DocumentRoot en `public/` y con el
DocumentRoot en la raíz.

---

## 1. `public/.htaccess` — el front controller

```apache
<IfModule mod_rewrite.c>
    RewriteEngine On

    # Sirve archivos y carpetas reales directamente
    RewriteCond %{REQUEST_FILENAME} -f [OR]
    RewriteCond %{REQUEST_FILENAME} -d
    RewriteRule ^ - [L]

    # Todo lo demas va al front controller (ruta relativa: funciona con
    # dominio propio y tambien bajo http://localhost/Copiway2/public/)
    RewriteRule . index.php [QSA,L]
</IfModule>

DirectoryIndex index.php
```

Línea por línea:

- **`RewriteEngine On`** — activa la reescritura de URLs (`mod_rewrite`).
- **`RewriteCond %{REQUEST_FILENAME} -f [OR]`** — si lo pedido es un archivo real (`-f`)…
- **`RewriteCond %{REQUEST_FILENAME} -d`** — …o una carpeta real (`-d`)…
- **`RewriteRule ^ - [L]`** — …no reescribas nada (`-`), entrégalo tal cual y para
  (`[L]` = *last*). Esto es lo que sirve `assets/css/app.css`, `assets/js/app.js`, etc.
- **`RewriteRule . index.php [QSA,L]`** — para todo lo demás, reescribe a `index.php`.
  `QSA` = *Query String Append* (conserva los `?parametros=...`); `L` = última regla.
- **`DirectoryIndex index.php`** — si se pide una carpeta, sirve `index.php`.

> No hay `RewriteBase`. El destino `index.php` es una **ruta relativa** a propósito: así
> la misma regla vale tanto para `http://copiway2.test/` como para
> `http://localhost/Copiway2/public/`, sin tener que ajustar nada.

## 2. `.htaccess` de la raíz — el reenvío a `public/`

```apache
<IfModule mod_rewrite.c>
    RewriteEngine On

    # Si Laragon apunta el DocumentRoot a la raiz del proyecto en vez de /public,
    # esta regla reenvia todo hacia la carpeta public.
    RewriteCond %{REQUEST_URI} !^/public/
    RewriteRule ^(.*)$ public/$1 [L]
</IfModule>
```

Si Apache sirve la carpeta del proyecto en vez de `public/`, cualquier petición que no
empiece ya por `/public/` se reenvía dentro de `public/`. La condición `!^/public/`
evita el bucle infinito.

Es también lo único que impide que alguien pida `config/database.php` por el navegador
cuando el proyecto se abre como `http://localhost/Copiway2/`. Ver
`../../guia/12-Seguridad.md` §10.

---

## Notas
- Necesita `mod_rewrite` activo en Apache (en Laragon lo está por defecto).
- El bloque `<IfModule>` hace que, si `mod_rewrite` no estuviera, Apache no dé error 500
  — pero entonces **ninguna ruta limpia funcionaría** y las carpetas internas quedarían
  expuestas.
- Es el equivalente de `public/router.php`, que hace lo mismo para el servidor de pruebas
  `php -S`.
- Gracias a esto las URLs son limpias (`/admin/comandas` en vez de
  `/index.php?ruta=admin/comandas`).
