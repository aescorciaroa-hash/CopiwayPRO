# `public/.htaccess`

## Ubicación
`public/.htaccess`

## Propósito
Configura **Apache** (el servidor de Laragon) para que **todas las URLs pasen por
`index.php`**, menos los archivos que existen de verdad.

## Contenido

```apache
<IfModule mod_rewrite.c>
    RewriteEngine On
    RewriteBase /

    # Sirve archivos y carpetas reales directamente
    RewriteCond %{REQUEST_FILENAME} -f [OR]
    RewriteCond %{REQUEST_FILENAME} -d
    RewriteRule ^ - [L]

    # Todo lo demas va al front controller
    RewriteRule ^ index.php [QSA,L]
</IfModule>

DirectoryIndex index.php
```

Línea por línea:
- **`RewriteEngine On`** — activa la reescritura de URLs (`mod_rewrite`).
- **`RewriteCond %{REQUEST_FILENAME} -f [OR]`** — condición: si lo pedido es un archivo
  (`-f`)...
- **`RewriteCond %{REQUEST_FILENAME} -d`** — ...o una carpeta (`-d`)...
- **`RewriteRule ^ - [L]`** — ...no reescribas nada (`-`), entrégalo tal cual y para
  (`[L]` = *last*). Esto sirve para `assets/css/app.css`, imágenes, etc.
- **`RewriteRule ^ index.php [QSA,L]`** — para todo lo demás, reescribe a `index.php`.
  `QSA` = *Query String Append* (conserva los `?parametros=...`). `L` = última regla.
- **`DirectoryIndex index.php`** — si se pide una carpeta, sirve `index.php`.

## Notas
- Necesita que `mod_rewrite` esté activo en Apache (en Laragon lo está por defecto).
- Es el equivalente de `public/router.php` pero para Apache.
- Gracias a esto las URLs son "limpias" (`/admin/comandas` en vez de
  `/index.php?ruta=admin/comandas`).
